# Projet Credit Card Default Prediction

## 📋 Description
This project is part of the DataGong training program. It focuses on predicting credit card defaults using exploratory data analysis and machine learning techniques.

## 📁 Project Structure
```
Projet_talktomydata/
├── credit_card_default.csv          # Dataset containing credit card information
├── projet_credit_card_eda.ipynb     # Exploratory Data Analysis notebook
├── projet_credit_card_machine_learning.ipynb  # Machine Learning models notebook
├── requirements.txt                  # Python dependencies
└── README.md                          # Project documentation
```

## 📊 Dataset
- **File**: `credit_card_default.csv`
- **Content**: Credit card transaction and customer information
- **Target**: Credit card default prediction

## 📚 Notebooks

### 1. EDA Notebook (`projet_credit_card_eda.ipynb`)
Exploratory Data Analysis including:
- Data overview and statistics
- Missing values analysis
- Data visualization
- Feature distributions
- Correlation analysis

### 2. Machine Learning Notebook (`projet_credit_card_machine_learning.ipynb`)
Machine learning implementation including:
- Data preprocessing
- Feature engineering
- Model training and evaluation
- Performance metrics
- Model comparison

## 🔧 Requirements
All dependencies are listed in `requirements.txt`. Install them using:

```bash
pip install -r requirements.txt
```

## 🚀 Getting Started

1. **Clone or download the project**
   ```bash
   cd Projet_talktomydata
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the notebooks**
   - Start with `projet_credit_card_eda.ipynb` for data exploration
   - Then run `projet_credit_card_machine_learning.ipynb` for model development
